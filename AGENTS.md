# Agent instructions

## Bento presentations

**REQUIRED SKILL:** Use `bento-slides` whenever the user asks for a presentation, slides, deck, презентацию, слайды, колоду, PowerPoint, or a `.bento.html` file.

- Skill: `.cursor/skills/bento-slides/SKILL.md`
- Schema and recipes: `.cursor/skills/bento-slides/agents.md`
- Output: `presentations/<Topic>.bento.html`

Do not wait for a plugin install. Read the skill, fetch the Bento shell if needed, author the `#bento-doc` JSON, and open the file to check every slide.
